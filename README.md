## Featured project

### 🐘 AI-Enabled IoT Human–Wildlife Conflict Detection System *(capstone, in progress)*

An early-warning system for human–wildlife conflict in the Wayanad region. It detects wildlife near settlements and livestock shelters, classifies the species, assesses severity, and routes alerts only to the people responsible for that zone.

- **Edge nodes:** ESP32 + microphone + PIR motion sensor, with sensor fusion to filter false positives before transmission
- **Central hub:** Raspberry Pi 4 running TensorFlow Lite models for species classification
- **Severity assessment:** fuzzy-logic scoring (Critical / High / Medium / Low) from species, confidence, zone and time of day
- **Alerting:** zone-based routing through Firebase and push notifications, with GSM SMS fallback when offline
- **Dashboard:** React + Leaflet map of events, node health and historical hotspots

**Stack:** ESP32 · Raspberry Pi · TensorFlow Lite · MQTT / LoRaWAN · Flask · Firebase · React
