## Projects

### 🛒 [SafeBasket](https://github.com/vinayarpillai2027/SafeBasket)
Paste an e-commerce product link and get a trust score, fake-review risk and a *Buy / Maybe / Don't Buy* recommendation.
- Pipeline: review extraction → VADER sentiment → grievance and fake-review detection → trust scoring → decision engine
- Heuristic fake-review signals: filler phrases, rating spikes, near-duplicate text, review bursts
- JWT auth, rate-limited REST API, per-user analysis history and dashboard
- **Stack:** Python · Flask · SQLAlchemy · React · VADER · SerpAPI

### 🌱 [Smart Grow Bench](https://github.com/vinayarpillai2027/zelbytes-arduino_vin)
A sensor-driven, safety-aware irrigation controller built during my IoT internship at Zelbytes.
- Finite state machine with cooldown and sensor-fault handling, non-blocking `millis()` timing
- Interrupt-driven emergency stop; relay-switched pump and valve
- Calibrated soil-moisture and light sensing, with documented test results
- Python bridge streaming Arduino telemetry to a cloud IoT API
- **Stack:** Arduino (C++) · DHT22 · Python (`pyserial`, `requests`)

### 🎨 [Aurora Gallery](https://github.com/vinayarpillai2027/Aurora_gallery)
A server-side rendered fine-art e-commerce site with a glassmorphism UI written in plain CSS.
- MVC structure with dynamic routing, reusable EJS partials and a session-backed cart
- Dockerised
- **Stack:** Node.js · Express · EJS · CSS · Docker

### 🐘 Human–Wildlife Conflict Detection *(capstone, in progress)*
An early-warning system for the Wayanad region that detects wildlife near settlements, classifies the species, scores severity and routes alerts to the right people for each zone.
- ESP32 edge nodes with audio + motion sensor fusion to filter false positives
- Raspberry Pi 4 hub running TensorFlow Lite models, with fuzzy-logic severity scoring
- Firebase-backed zone routing, with GSM SMS fallback when offline
- **Stack:** ESP32 · Raspberry Pi · TensorFlow Lite · LoRaWAN / MQTT · Firebase · React
